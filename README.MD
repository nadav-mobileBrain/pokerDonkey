# Poker Donkey

Poker Donkey is a mobile application designed to help poker players track and analyze their home game statistics. Built with React Native and Expo, this app offers a comprehensive solution for managing poker leagues, tracking game results, and viewing detailed player statistics.

## Features

- Create and join poker leagues
- Track individual game results
- View detailed player statistics
- Analyze profit/loss trends
- Google Sign-In integration
- Real-time updates and notifications
- Cross-platform compatibility (iOS and Android)

## Installation

To set up the development environment:

1. Clone the repository:

   ```
   git clone https://github.com/your-username/pokerdonkey.git
   cd pokerdonkey
   ```

2. Install dependencies:

   ```
   npm install
   ```

3. Set up environment variables (if required).

## Running the App

- To start the Expo development server:

  ```
  npm start
  ```

- To run on Android:

  ```
  npm run android
  ```

- To run on iOS:
  ```
  npm run ios
  ```

## Building for Production

This project uses EAS (Expo Application Services) for building. To create a production build:

1. Install EAS CLI globally:

   ```
   npm install -g eas-cli
   ```

2. Configure your EAS project (if not already done).

3. Run the build command:
   ```
   eas build --platform all
   ```

## Technologies Used

- React Native
- Expo
- React Navigation
- Google Sign-In
- Formik & Yup for form handling and validation
- Aptabase for analytics
- Bugsnag for error tracking
